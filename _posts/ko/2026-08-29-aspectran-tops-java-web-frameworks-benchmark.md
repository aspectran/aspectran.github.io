최근 오픈소스 웹 프레임워크 성능 벤치마크 프로젝트인 **[Web Frameworks Benchmark](https://github.com/the-benchmarker/web-frameworks)**에 Aspectran이 공식 등록되었습니다.

그리고 오늘 공개된 최신 벤치마크 결과에서, Aspectran은 **전체 Java 웹 프레임워크 중 평균 처리량(Average RPS) 1위** 및 **동시성 64 / 256 구간 Java 1위**라는 놀라운 성적을 기록했습니다.
<!--more-->

전 세계 353개의 다양한 언어와 웹 프레임워크들이 참가한 이번 벤치마크에서, Aspectran은 C++, Rust, Go 등 네이티브 언어 진영과 어깨를 나란히 하며 글로벌 상위 12%(전체 44위)의 고성능을 입증했습니다.

## 📊 Web Frameworks Benchmark 개요

[Web Frameworks Benchmark](https://github.com/the-benchmarker/web-frameworks)는 공정한 독립 컨테이너 환경에서 각 언어와 프레임워크의 HTTP 요청 처리 성능을 측정하는 글로벌 오픈소스 벤치마크 프로젝트입니다.

* **테스트 항목**:
    * `GET /` (기본 루트 요청)
    * `GET /user/${id}` (경로 변수 파싱 및 텍스트 응답)
    * `POST /user` (간단한 POST 본문 처리)
* **측정 동시성(Concurrency)**: 64, 256, 512 동시 연결 환경
* **실행 환경**: Java 21, Linux 컨테이너 격리 환경

## 🌟 주요 결과 분석

### 1. 전 구간에 걸친 압도적인 초기 응답성과 안정성
많은 엔터프라이즈 프레임워크들이 동시성 64 구간에서 스레드 풀 초기화 오버헤드나 웜업 지연으로 인해 2,000~6,000 req/s 수준에 머무른 반면, Aspectran은 **동시성 64에서부터 34,305 req/s**를 뿜어내며 전체 Java 프레임워크 중 1위를 기록했습니다.

동시성이 256, 512로 증가함에 따라 **36,482 req/s**, **37,807 req/s**로 성능이 선형적으로 향상되며 고부하 상황에서도 지연 없는 안정적인 처리량을 보여주었습니다.

### 2. 베이스 엔진(Undertow)을 뛰어넘는 시너지
Aspectran은 Undertow 임베디드 서버(`aspectran-with-undertow`)를 기반으로 구동됩니다. 순수 Undertow(평균 35,741.3 req/s)와 비교했을 때, Aspectran은 상위 레벨 프레임워크 계층이 추가되었음에도 오히려 더 높은 **평균 36,198.0 req/s**를 기록했습니다. 이는 Aspectran의 `LightRequestHandlerFactory`와 트랜슬릿 실행 파이프라인이 런타임 오버헤드를 유발하지 않고 엔진의 잠재력을 극한까지 끌어올렸음을 증명합니다.

### 3. 주류 엔터프라이즈 프레임워크 대비 2배 이상의 처리량
Spring(17,394 req/s), Spring WebFlux(15,039 req/s) 대비 **2배 이상의 높은 처리량**을 기록했으며, Quarkus(26,596 req/s), Micronaut(23,874 req/s) 대비해서도 **1.3배~1.5배 이상** 앞선 결과를 보여주었습니다.

## 💡 어떻게 두 마리 토끼를 잡을 수 있었을까?

전통적인 웹 프레임워크 시장에서는 흔히 **"기능이 풍부한 엔터프라이즈 프레임워크는 무겁고 느리며, 빠른 프레임워크는 기능이 빈약한 단순 라우터에 불과하다"**는 인식이 지배적이었습니다.

Aspectran은 설계 초기부터 **"엔터프라이즈 환경에 완벽히 대응할 수 있는 아키텍처와 로우레벨 엔진 수준의 극한 성능을 동시에 달성한다"**는 목표로 개발되었습니다.

### 1. 트랜슬릿(Translet) 기반의 최단 경로 실행 (Shortest Path Execution)
Aspectran의 핵심 단위인 트랜슬릿은 요청 수신부터 파라미터 매핑, 액션 실행, 변환(Transform) 및 응답 렌더링에 이르는 전체 라이프사이클을 가장 단순하고 직관적인 파이프라인으로 연결합니다. 불필요한 레이어 간 데이터 복사나 다중 필터 계층을 걷어내어 최단 경로로 응답을 생성합니다.

### 2. 오버헤드 없는 Activity Context & 경량 IoC/AOP
요청 처리 시마다 무거운 런타임 리플렉션이나 복잡한 프록시 조회를 반복하는 대신, 사전에 정밀하게 최적화된 Activity Context를 통해 최소한의 메모리 할당만으로 IoC/DI와 AOP를 적용합니다.

### 3. 단순 마이크로 라우터가 아닌, 완전한 엔터프라이즈 스택
이번 벤치마크에서 더욱 뜻깊은 점은 Aspectran이 성능 측정을 위해 필수 기능을 깎아낸 미니멀 프레임워크가 아니라는 점입니다. Aspectran은 이미 **완전한 IoC/DI 컨테이너, 선언적 트랜잭션, 스케줄러(Scheduler), 데몬(Daemon), 세션 클러스터링, APON 데이터 포맷, 템플릿 엔진** 등 엔터프라이즈 시스템 구축에 필요한 모든 컴포넌트를 내장한 상태에서 이 성능을 입증했습니다.

## 🎯 마치며

이번 벤치마크 결과는 타협 없는 아키텍처 설계와 지속적인 최적화의 결실입니다.

Aspectran은 앞으로도 대규모 트래픽을 처리해야 하는 클라우드 네이티브 서비스부터 안정성이 최우선인 기업용 미션 크리티컬 시스템에 이르기까지, 최고의 성능과 개발 생산성을 동시에 제공할 수 있도록 끊임없이 진화해 나갈 것입니다.

Aspectran의 벤치마크 구성 코드와 실행 설정은 [Web Frameworks GitHub 저장소](https://github.com/the-benchmarker/web-frameworks/tree/master/java/aspectran)에서 직접 확인하실 수 있습니다.
