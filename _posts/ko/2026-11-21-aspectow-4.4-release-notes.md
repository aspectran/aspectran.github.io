이번 **Aspectow v4.4.0** 릴리즈는 PWA 기반 **OS 레벨 Web Push 실시간 알림 및 통합 알림 센터(Notification Center)** 신설, 분산 클러스터 전역 알림 동기화, 애플리케이션 런타임 환경을 정밀 진단하는 **프레임워크 컴포넌트 뷰어(Framework Components Viewer)** 및 15종 전용 인스펙터 구축, **프레임워크 해부도(Framework Anatomy)** 고도화, **빌드 감사(Build Audit) 날짜 범위 필터링 및 CSV 내보내기**, **실시간 고유 활성 사용자 세션 테이블 뷰**, **웹소켓 및 브라우저 생명주기 연동 제어**, 그리고 **대시보드 차트 모바일 인터랙션 혁신**과 **Aspectran 9.8.4 / Netty 4.2.21 연동**을 아우르는 대규모 마이너 기능 확장 및 플랫폼 완성도 제고 릴리즈입니다.
<!--more-->

클러스터 환경 전반에 걸쳐 신뢰성 있는 실시간 알림 파이프라인을 구축함과 동시에, 런타임 리플렉션과 안전한 인스펙터 체계를 통해 무중단으로 핵심 인프라 구성을 탐색하고 단일 관제 화면에서 모든 노드의 컴포넌트 스펙과 해부도를 일목요연하게 점검할 수 있는 엔터프라이즈 운영 환경을 제공합니다.

## 🚀 새로운 기능

* **PWA Web Push 실시간 알림 시스템 및 통합 알림 센터(Notification Center) 구축**
    - **RFC 8292 VAPID 표준 기반 OS 레벨 백그라운드 푸시 알림**:
        - 별도의 서드파티 상용 서비스나 네이티브 앱 설치 없이, W3C Web Push 표준 및 VAPID 프로토콜을 기반으로 데스크톱(Windows, macOS, Linux) 및 모바일(Android, iOS 16.4+) 전반에 OS 네이티브 알림 배너를 실시간으로 전송합니다.
        - 서비스 워커(`sw.js`)와 연동되어 브라우저 탭이나 PWA 창이 닫혀 있는 상태에서도 백그라운드에서 실시간 알림을 수신하고, 알림 클릭 시 해당 이벤트의 상세 분석 화면(모니터링 대시보드, 빌드 감사 등)으로 즉시 이동합니다.
    - **5대 핵심 도메인 이벤트 커버리지**:
        - **시스템 모니터링 경보(MONITORING)**: 노드 연결 중단(Node Down), CPU 사용률 임계치 초과, 메모리 사용률 임계치 초과 및 정상 복구.
        - **분산 스케줄러(SCHEDULER)**: 스케줄러 잡 실행 실패 및 비정상 예외 발생.
        - **빌드 및 배포(BUILD)**: 브랜치 빌드/배포 성공 및 빌드 실패·롤백 통보.
        - **보안 감사(SECURITY)**: 비인가 IP 접근 감지, 관리자 계정 잠김 등 비정상 보안 이벤트.
        - **원격 명령(COMMAND)**: 클러스터 노드 대상 일괄 비동기 원격 명령 실행 완료 통보.
    - **상태 머신(State Machine) 기반 알람 폭탄 방지 및 정상 복구(RESOLVED) 알림**:
        - 주기적으로 반복 수집되는 모니터링 메트릭 환경에서 동일한 경보가 무한 반복 발송되는 피로도를 차단하기 위해 상태 머신을 도입했습니다.
        - 수치가 임계치를 처음 초과할 때 1회만 경보(`CRITICAL`/`WARN`)를 발송하고 상태를 `ALERTING`으로 전이한 뒤 추가 발송을 억제하며, 지표가 안정화되면 `[RESOLVED] 정상 복구 알림`을 1회 발송하고 `NORMAL` 상태로 복귀합니다.
    - **클러스터 다중 노드 중복 알림 방지 (Redis 분산 락 연동)**:
        - 클러스터 내 노드 이탈/합류 등 전역 이벤트 발생 시 N개의 노드가 동시에 알림을 디스패치하여 사용자에게 중복 발송되는 현상을 방지하고자, Redis 원자적 분산 락(`SET NX EX`) 메커니즘을 적용하여 최초 락을 획득한 단 1개 노드만이 발송을 전담하도록 보장합니다.
    - **VAPID 키 중앙 영속화 및 브라우저 자동 자가 치유(Auto Re-subscribe)**:
        - 클러스터 기동 시 DB(`asc_vapid_key`)를 기반으로 타원곡선(EC secp256r1) 키 쌍을 공유하여 노드 간 키 불일치로 인한 401 오류를 원천 차단했습니다.
        - 클라이언트 측 `notification-client.js`가 서버의 공개키 변경을 자동 감지하여 기존 구독을 갱신하는 자동 재구독 메커니즘을 완비했습니다.
    - **엔터프라이즈 방화벽/폐쇄망 대응을 위한 선언적 2단계 계층형 알림 비활성화 모델**:
        - 외부 인터넷 통신이 차단된 사내망 환경을 고려하여, `notification-rules.xml`의 빈 정의 조합만으로 'Web Push만 비활성화(인앱 알림만 유지)' 또는 '알림 시스템 전체 완전 비활성화'를 선언적으로 유연하게 전환할 수 있습니다.
    - **통합 알림 UI/UX 및 권한 기반 수신 설정**:
        - 상단 네비게이션 바에 🔔 알림 버튼 및 읽지 않은 알림 카운트 뱃지를 신설했습니다.
        - 🔔 클릭 시 노출되는 모달을 통해 최근 알림 이력 확인, 모두 읽음/비우기 처리를 지원하며, 기기별 푸시 수신 마스터 스위치 및 CPU/메모리 임계치(%), 도메인별 수신 여부를 사용자가 직접 설정할 수 있습니다.
        - 관리자 메뉴에 푸시 구독 현황 모니터링, VAPID 키 재생성, 테스트 푸시 발송 관리 도구를 구축했습니다.

* **프레임워크 컴포넌트 뷰어(Framework Components Viewer) 신설 및 15종 핵심 컴포넌트 전용 인스펙터 구축**
    - **무중단 정밀 진단 아키텍처**: `aspectow-node`에 `ComponentInspectorService` 및 `ComponentInspector` 기반의 진단 레이어를 구축하여, 외부 라이브러리 하드 의존성 없이 실행 중인 `ActivityContext`와 `BeanRegistry`의 컴포넌트 스펙을 런타임 리플렉션으로 안전하게 추출합니다.
    - **15종 핵심 컴포넌트 전용 인스펙터 제공**:
        - **서버 및 코어 인프라**: 임베디드 웹 서버(`Server`), 애플리케이션 어댑터(`ApplicationAdapter`)
        - **세션 및 웹 계층**: 세션 관리자(`SessionManager`), 뷰 디스패처(`ViewDispatcher`), CORS 처리기(`CorsProcessor`), 멀티파트 업로더(`Multipart`)
        - **데이터 접근 및 캐시**: 데이터소스(`DataSource`), MyBatis(`SqlSessionFactory`), JPA(`EntityManagerFactory`), Redis 클라이언트(`RedisClient`)
        - **스케줄링 및 비동기**: 스케줄러(`Scheduler`), 비동기 작업 실행기(`AsyncTaskExecutor`)
        - **국제화 및 렌더링**: 로케일 리졸버(`LocaleResolver`), 메시지 소스(`MessageSource`), 템플릿 렌더러(`TemplateRenderer`)
    - **분산 클러스터 원격 진단 지원**: `LocalCommandService`와 `RemoteCommandManager`를 통해 중앙 콘솔에서 원격 클러스터 노드의 컴포넌트 스펙을 비동기 조회하고, 'Refresh' 버튼으로 즉시 캐시를 갱신할 수 있습니다.

* **프레임워크 해부도(Framework Anatomy) 고도화 및 클러스터 통합**
    - **`AnatomyDataService` 도입**: 클러스터 환경을 지원하는 데이터 수집 레이어를 신설하여 로컬 및 원격 노드의 `ActivityContext` 구조를 동적으로 탐색합니다.
    - **대표 노드 기반 질의 위임**: `NodeConsoleHelper`에 `findRepresentativeNodeId()` 및 `getAvailableGroups()`를 도입하여 클러스터 노드 쿼리를 중앙에서 안전하게 집계합니다.
    - **민감정보 마스킹(Credential Masking)**: 프레임워크 설정 APON 추출 시 비밀번호, 인증 키 등 민감 정보를 자동으로 마스킹 처리하여 보안 감사 요건을 충족합니다.
    - **사이드바 내비게이션 분리**: 관제 콘솔 메뉴에서 **컴포넌트 뷰어(Components)**와 **프레임워크 해부도(Anatomy)**를 독립된 최상위 메뉴로 분리했습니다.

* **빌드 감사(Build Audit) 날짜 범위 필터링, CSV 내보내기 및 공통 페이지네이션 체계 구축**
    - **다차원 날짜 범위 필터링(Date Range Filtering)**: 빌드 감사 및 계정 관리 화면에 `DateRange` 유틸리티 및 `dayjs` 연동 기간 검색을 도입하여, 특정 기간 동안 수행된 빌드 및 작업 이력을 직관적으로 필터링할 수 있습니다.
    - **CSV 데이터 내보내기 지원**: 감사 요건 및 외부 보고서 작성을 위해 조회된 빌드 감사 내역을 UTF-8 BOM 인코딩 기반의 CSV 파일로 즉시 다운로드할 수 있는 기능을 추가했습니다.
    - **Thymeleaf 페이지네이션 공통 프래그먼트 구조화**: 여러 관리 화면에 분산되어 있던 페이지네이션 마크업과 스크립트를 재사용 가능한 `pagination.html` 템플릿 프래그먼트로 일원화하여 UI 일관성을 확보했습니다.

* **실시간 고유 활성 사용자 세션 테이블 뷰(Active Users Session Table View) 추가**
    - 기존 세션 이벤트 목록 외에, 현재 로그인된 고유 사용자들의 활성 세션 상태(사용자 ID, 세션 ID, 최근 활동 시간, IP 주소, 국가 코드 등)를 직관적으로 조회할 수 있는 전용 테이블 뷰를 추가했습니다.
    - 테스트 환경에서 다중 세션 관리자를 일괄 검사할 수 있도록 `getAllSessionManagers()` 지원을 추가했습니다.

* **콘솔 프로그레시브 웹 앱(PWA, Progressive Web App) 공식 지원**
    - 웹앱 매니페스트(`manifest.webmanifest`)와 서비스 워커(`sw.js`)를 연동하여 데스크톱 및 모바일 환경에서 독립형(Standalone) 앱 설치 및 실행을 지원합니다.
    - 고해상도 앱 아이콘 및 마스커블(Maskable) 아이콘 리소스를 완비하고, 정적 에셋 캐싱으로 오프라인 네트워크 복원력을 높였습니다.

* **글로벌 노드 메타데이터 홀더(`NodeManagerHolder`) 도입**
    - 동일 JVM 내 다중 컨텍스트 환경에서 활성 `NodeManager` 인스턴스에 정적으로 접근할 수 있는 `NodeManagerHolder`를 신설했습니다.
    - 노드 ID 및 그룹 ID를 시스템 프로퍼티와 동기화하고 빌드/소멸 라이프사이클에 맞추어 안전하게 관리합니다.

## 🚀 개선 사항

* **웹소켓 및 클라이언트 브라우저 생명주기 연동 제어 고도화**
    - **화면 전환/이탈 시 불필요한 재연결 및 노드 상태 깜빡임 방지**:
        - `BaseClient`, `WebsocketClient`, `ConsoleClient`에 모던 브라우저 생명주기(`beforeunload`, `pagehide`, `pageshow`) 핸들러를 구축했습니다.
        - 사용자가 대시보드나 콘솔 화면을 벗어날 때 웹소켓 종료 시점에 `unloading` 상태를 즉시 감지하여, 불필요한 백그라운드 재연결 시도와 콘솔 화면에서 노드 상태가 `DEAD`로 찰나에 깜빡이는 시각적 노이즈를 원천 차단했습니다.
    - **모바일 백그라운드 전환 후 포그라운드 복귀(Resume) 안정화**:
        - 모바일 브라우저가 백그라운드에서 복귀할 때 소켓 상태를 점검하고 필요시 즉각 재연결을 시도하는 `onResume` 메커니즘을 정교화했습니다.
    - **화면단 보일러플레이트 코드 일원화**:
        - 클라이언트 라이브러리 차원에서 생명주기를 완벽히 제어함에 따라, `nodes.html` 등 개별 뷰 템플릿에 존재하던 임시 방어 코드(`isUnloading` 플래그 및 수동 클라이언트 추적)를 전면 제거하여 화면 코드를 간결하게 정돈했습니다.

* **대시보드 차트 모바일 인터랙션 혁신 및 타깃 줌인 고도화**
    - **모바일 더블 탭 확대 최적화**: 캔버스에 `touch-action: manipulation`을 적용하고 더블 탭 판정 임계값(450ms, 36px)을 완화하여 터치 조작성을 향상했습니다.
    - **스크롤 간섭 및 중복 이벤트 방지**: `touchmove`/`touchcancel` 처리를 정교화하여 스크롤 중 의도치 않은 확대를 방지하고, `touchend` 직후 합성 `dblclick`으로 인한 즉시 리셋 버그를 해결했습니다.
    - **경계 좌표 클램핑 및 타깃 줌인**: 여백 터치 시에도 `chartArea` 범위로 좌표를 자동 보정하며, 선택된 X축 지점을 기억하여 상단 돋보기(+) 줌인 버튼 클릭 시 해당 지점 중심으로 확대되도록 개선했습니다.
    - **레이아웃 단순화**: 중복 템플릿 의존성을 제거하고 `dashboard.html` 내에 그룹 바 구조를 인라인화했습니다.

* **세션 패널 및 대시보드 뷰어 레이아웃 안정화**
    - 활성 사용자 세션 테이블 뷰 모드를 해제하고 이전 화면으로 복귀할 때, 기존 세션 패널의 스크롤 위치를 온전히 복원하도록 개선했습니다.
    - 반응형 환경에서의 알림 모달 레이아웃 및 뱃지 스타일을 최적화했습니다.
