This **Aspectow v4.4.0** release is a major milestone that introduces **PWA-based OS-level Web Push real-time notifications and an integrated Notification Center**, cluster-wide notification deduplication and synchronization, the **Framework Components Viewer** for deep runtime diagnostics across 15 dedicated component inspectors, upgraded **Framework Anatomy**, **Build Audit multi-dimensional date range filtering and CSV export**, a dedicated **Active Users Session Table View**, **WebSocket and browser lifecycle integration**, enhanced **dashboard chart mobile interactions**, and the official integration of **Aspectran 9.8.4** and **Netty 4.2.21**.
<!--more-->

Through a reliable real-time alerting pipeline coupled with runtime reflection and a safe inspector architecture, operators can inspect key infrastructure components with zero downtime and receive instant OS-level alerts across distributed environments from a single centralized console.

## 🚀 New Features

* **PWA Web Push Real-Time Notifications and Integrated Notification Center**
    - **RFC 8292 VAPID-Standard OS-Level Background Push Notifications**:
        - Delivers real-time OS-native push notifications across desktop (Windows, macOS, Linux) and mobile (Android, iOS 16.4+) environments based on the W3C Web Push standard and VAPID protocol, without requiring native app installations or paid third-party push services.
        - Integrates with the background Service Worker (`sw.js`) to wake up and receive alerts even when browser tabs or PWA windows are completely closed. Clicking an alert banner navigates directly to the relevant analytical view (e.g. monitoring dashboard, build audit history).
    - **Full Coverage of Five Core Domain Events**:
        - **System Monitoring Alerts (MONITORING)**: Node down events, CPU usage threshold exceeded, memory usage threshold exceeded, and resource recovery notifications.
        - **Distributed Scheduler (SCHEDULER)**: Scheduler job execution failures and unhandled runtime exceptions.
        - **Build & Deployment (BUILD)**: Branch build/deployment success notices, build failure, and rollback alerts.
        - **Security Auditing (SECURITY)**: Unauthorized IP access attempts, administrative account lockouts, and anomalous access events.
        - **Remote Commands (COMMAND)**: Completion notifications for asynchronous batch remote commands across cluster nodes.
    - **State-Machine-Driven Alert Storm Throttling and Recovery Notifications**:
        - Introduces a state machine to eliminate alert fatigue caused by periodic, continuous metric sampling.
        - Sends an alert (`CRITICAL`/`WARN`) only once when a metric first exceeds the user-configured threshold, transitions to the `ALERTING` state, and suppresses further redundant notifications while the condition persists. Once the metric stabilizes below the threshold, it sends a single `[RESOLVED]` recovery notice and returns to the `NORMAL` state.
    - **Cluster-Wide Multi-Node Notification Deduplication via Redis Distributed Locks**:
        - Solves the multi-node duplicate alert problem where every cluster node receives membership events (e.g., node down or join) simultaneously. By using Redis atomic distributed locks (`SET NX EX`), exactly one node wins the lock and dispatches the notification, ensuring zero duplicate alerts to user devices.
    - **VAPID Key Central Persistence and Client-Side Auto-Healing**:
        - Persists elliptic curve (EC secp256r1) VAPID key pairs in the database (`asc_vapid_key`), ensuring all cluster nodes share an identical key set and preventing 401 Unauthorized errors from push service providers.
        - Includes an automatic healing mechanism in `notification-client.js` that detects server public key updates, automatically unsubscribing outdated registrations and re-subscribing with the fresh key.
    - **Declarative Two-Tier Notification Disabling for Enterprise Air-Gapped Environments**:
        - Designed for enterprise intranets and financial air-gapped environments where outbound internet access to push services (FCM, APNs, autopush) is blocked. Operators can declaratively toggle between "Web Push disabled (in-app notifications only)" or "Full notification system disabled" simply by modifying bean definitions in `notification-rules.xml`.
    - **Unified Notification UI/UX and Permission-Aware Settings**:
        - Adds an interactive bell (🔔) button with an unread badge counter to the top navigation header.
        - Provides a dedicated modal to review recent alerts, mark all as read, clear history, and customize device-specific push toggles, CPU/memory thresholds (%), and domain event subscriptions.
        - Offers administrative management tools to monitor device subscriptions, regenerate VAPID keys, and dispatch test push notifications.

* **Framework Components Viewer and 15 Dedicated Component Inspectors**
    - **Zero-Downtime Precision Diagnostics**: Built a diagnostics layer in `aspectow-node` based on `ComponentInspectorService` and `ComponentInspector`. Safely extracts component specifications from running `ActivityContext` and `BeanRegistry` instances via runtime reflection without introducing hard dependencies on external libraries.
    - **15 Dedicated Component Inspectors**:
        - **Server & Core Infrastructure**: Embedded Web Server (`Server`), Application Adapter (`ApplicationAdapter`)
        - **Session & Web Layer**: Session Manager (`SessionManager`), View Dispatcher (`ViewDispatcher`), CORS Processor (`CorsProcessor`), Multipart Uploader (`Multipart`)
        - **Data Access & Caching**: Data Source (`DataSource`), MyBatis (`SqlSessionFactory`), JPA (`EntityManagerFactory`), Redis Client (`RedisClient`)
        - **Scheduling & Async Tasks**: Scheduler (`Scheduler`), Asynchronous Task Executor (`AsyncTaskExecutor`)
        - **Internationalization & Rendering**: Locale Resolver (`LocaleResolver`), Message Source (`MessageSource`), Template Renderer (`TemplateRenderer`)
    - **Distributed Cluster Remote Diagnostics**: Queries remote cluster node component specifications asynchronously via `LocalCommandService` and `RemoteCommandManager`, with a 'Refresh' button to immediately invalidate caches and retrieve fresh states.

* **Framework Anatomy Enhancements and Cluster Integration**
    - **`AnatomyDataService` Introduction**: Added a cluster-compatible data retrieval service to dynamically introspect `ActivityContext` hierarchies across local and remote nodes.
    - **Representative Node Delegation**: Introduced `findRepresentativeNodeId()` and `getAvailableGroups()` in `NodeConsoleHelper` to safely centralize and aggregate cluster queries without exposing node details.
    - **Credential Masking**: Automatically masks sensitive data such as passwords, secret tokens, and keys when extracting framework configurations in APON format to ensure compliance with security audit policies.
    - **Sidebar Navigation Reorganization**: Reorganized the console sidebar menu to separate **Components** and **Anatomy** into distinct top-level menu entries.

* **Build Audit Date Range Filtering, CSV Export, and Unified Pagination**
    - **Multi-Dimensional Date Range Filtering**: Introduced the `DateRange` utility integrated with `dayjs` across build audit and user management views, enabling administrators to filter build and audit records over custom date ranges.
    - **CSV Data Export**: Added support for exporting filtered build audit records directly into UTF-8 BOM encoded CSV files for audit reporting and compliance requirements.
    - **Thymeleaf Reusable Pagination Fragments**: Standardized scattered pagination markup and scripts into a modular `pagination.html` fragment, ensuring consistent UI behaviors across console views.

* **Real-Time Unique Active Users Session Table View**
    - Added a dedicated session table view alongside the session events stream to inspect real-time active sessions for distinct authenticated users, displaying username, session ID, last access time, IP address, and country code.
    - Added `getAllSessionManagers()` to inspect all registered session managers in test environments, ensuring monitoring reliability.

* **Official Progressive Web App (PWA) Support in Console**
    - Integrated a Web App Manifest (`manifest.webmanifest`) and Service Worker (`sw.js`) to support installing and running the Aspectow Console as a standalone application on desktop and mobile.
    - Packaged high-resolution responsive app icons and maskable icon assets, and improved offline resilience through static asset caching.

* **Global Node Metadata Holder (`NodeManagerHolder`)**
    - Introduced `NodeManagerHolder` to provide static global access to the active `NodeManager` instance across multiple contexts within the same JVM.
    - Synchronizes node ID and group ID with system properties and binds safely to build and destroy lifecycle hooks.

## 🚀 Improvements

* **WebSocket and Client Browser Lifecycle Management**
    - **Suppression of Redundant Reconnects and Node Status Flickering on Navigation**:
        - Integrated modern browser lifecycle events (`beforeunload`, `pagehide`, and `pageshow`) into `BaseClient`, `WebsocketClient`, and `ConsoleClient`.
        - Detects page unloads before WebSocket termination, completely suppressing background reconnection timers and preventing nodes from momentarily flickering into a `DEAD` status when users navigate away.
    - **Resilient Mobile Background-to-Foreground Resumption**:
        - Refined the `onResume` handling to verify socket health immediately when returning from mobile background states and execute instant reconnection when needed.
    - **Template Boilerplate Elimination**:
        - By encapsulating lifecycle management within the client classes, ad-hoc `isUnloading` flags and manual client tracking arrays in view templates like `nodes.html` were completely eliminated.

* **Dashboard Chart Mobile Interaction and Targeted Zoom-in**
    - **Mobile Double-Tap Optimization**: Applied `touch-action: manipulation` to chart canvases and relaxed double-tap thresholds (450ms, 36px) to improve touch ergonomics.
    - **Scroll and Duplicate Event Prevention**: Refined `touchmove` and `touchcancel` handling to prevent accidental zooming during page scrolling, and resolved the synthetic `dblclick` timing bug that triggered an immediate zoom reset right after `touchend`.
    - **Coordinate Clamping and Targeted Zoom-in**: Automatically clamps touch coordinates to the `chartArea` boundaries near margins, and tracks selected X-axis points to center zooming on the selected data point when clicking the zoom-in (+) button.
    - **Layout Simplification**: Inlined the group bar structure directly into `dashboard.html` and eliminated redundant template dependencies.

* **Session Panel and Dashboard Viewer Layout Stabilization**
    - Perfectly restores previous session panel scroll positions when switching back from the active users table view.
    - Refined responsive notification modal layouts, badge styling, and mobile responsiveness.
